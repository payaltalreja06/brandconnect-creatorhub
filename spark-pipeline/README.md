# spark-pipeline/

This directory is the **data engineering layer** of BrandConnect CreatorHub.
It is completely independent of `/frontend` and `/backend`.

## Directory Structure

```
spark-pipeline/
├── Dockerfile                  # PySpark container image
├── docker-compose.yml          # Spark + Airflow services
├── requirements.txt            # Python deps for Spark image
├── jobs/
│   └── etl.py                  # ★ Main PySpark ETL script
├── dags/
│   └── youtube_etl_dag.py      # ★ Airflow DAG
└── data/
    └── youtube/
        ├── raw/
        │   ├── TEMPLATE_channel.jsonc   ← read this first
        │   ├── channel_1.json           ← fill in your 5 channels
        │   ├── channel_2.json
        │   ├── channel_3.json
        │   ├── channel_4.json
        │   └── channel_5.json
        └── processed/
            └── (auto-generated by ETL)
```

---

## Step 1 — Fill in Channel Data

Open each `data/youtube/raw/channel_N.json` file and replace the placeholder
values with real YouTube channel + video data. See `TEMPLATE_channel.jsonc`
for field descriptions.

**Required fields per channel:**

| Field        | Type   | Example                          |
|------------- |--------|----------------------------------|
| channelId    | string | `"UCxxxxxx"`                    |
| channelName  | string | `"Tech With Ravi"`              |
| subscribers  | number | `480000`                        |
| totalViews   | number | `12000000`                      |
| totalVideos  | number | `150`                           |
| videos[]     | array  | See below                        |

**Required fields per video:**

| Field        | Type   | Example                          |
|------------- |--------|----------------------------------|
| videoId      | string | `"dQw4w9WgXcQ"`                |
| title        | string | `"Top 10 Python Tips"`         |
| publishedAt  | string | `"2025-03-15T10:00:00Z"`       |
| views        | number | `250000`                        |
| likes        | number | `18000`                         |
| comments     | number | `940`                           |
| duration     | string | `"PT8M45S"` (ISO 8601)         |

---

## Step 2 — Start the Stack

```bash
cd spark-pipeline
docker compose up --build
```

Services:
- **Spark container** → stays running, ready for `spark-submit`
- **Airflow UI** → http://localhost:8080  (user: `admin`, pass: `admin`)

---

## Step 3 — Run ETL Manually (dev mode)

```bash
# Trigger ETL directly without Airflow
docker exec spark spark-submit /opt/spark/jobs/etl.py
```

Output files will appear in `data/youtube/processed/{channelId}.json`.

---

## Step 4 — Run via Airflow

1. Open http://localhost:8080
2. Enable the DAG: `brandconnect_youtube_etl`
3. Trigger manually or wait for the daily schedule (midnight UTC)

Pipeline tasks:
```
validate_raw_data  →  spark_etl_youtube  →  verify_etl_output
```
